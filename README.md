# مزاد مسارك للوحات المميزة — النسخة الأولى

هذه نسخة Front-End مستقلة تعيد بناء واجهة الصورة المرفقة بشكل قريب جداً من حيث:
- الاتجاه العربي RTL
- رأس الموقع
- لوحة المزاد والعداد
- السعر واللوحة السعودية
- بطاقات المعلومات والعمولة
- التعليقات والبث
- واجهة متجاوبة للجوال والكمبيوتر

## التشغيل
لا تحتاج قاعدة بيانات أو تثبيت مكتبات.
افتح `index.html` مباشرة في المتصفح.

## الرفع على GitHub Pages
1. أنشئ Repository جديد.
2. ارفع الملفات الثلاثة: `index.html`, `styles.css`, `app.js`.
3. من Settings > Pages اختر Deploy from branch.
4. اختر الفرع `main` والمجلد `/root`.
5. احفظ وانتظر رابط الموقع.

## ملاحظة
هذه النسخة الأولى واجهة تجريبية. أزرار الوقت والإدارة تعمل محلياً في المتصفح، لكن المزايدة الحقيقية وتسجيل المستخدمين وحفظ اللوحات تحتاج Backend وقاعدة بيانات في المرحلة التالية.
